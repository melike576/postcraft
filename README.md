# 🍯 PostCraft — Sosyal Medya İçerik Stüdyosu

**PostCraft**, içerik üreticilerinin X (Twitter), Instagram ve LinkedIn gönderilerini akıllı asistan ve canlı etkileşim skoru eşliğinde hazırlayıp, platforma özel gerçekçi mockup'larda önizleyebildiği hepsi-bir-arada bir sosyal medya stüdyosudur.

---

## ✨ Özellikler

* **Çoklu Platform Önizleme:**
  * 🐦 **X (Twitter):** Standart gönderi ve 🧵 **Tweet Zinciri (Thread Modu)**
  * 📱 **Instagram:** Tekli gönderi ve 🎠 **Çoklu Slayt (Carousel Modu)**
  * 💼 **LinkedIn:** Tekli görsel ve 📄 **Çok Sayfalı PDF / Doküman Slayt Önizlemesi**
* **📊 Canlı Etkileşim Skoru:** Gönderinin uzunluk, kanca, CTA, etiket ve okunabilirlik kriterlerini canlı puanlayan 0–100 gösterge motoru.
* **✨ Akıllı İçerik Asistanı:** Yazılan metnin konusunu (Tasarım, Yazılım, Kariyer, Üretkenlik) analiz edip konuya özel kancalar, tonlamalar ve popüler etiketler öneren zeka motoru.
* **📸 2x Retina PNG İndir:** Mockup önizlemesini tek tıkla yüksek çözünürlüklü görsel olarak dışa aktarma.
* **📅 İnteraktif İçerik Takvimi:** Aylık takvim gridi ve zaman çizelgesi ile gönderileri planlama ve yönetme.
* **📋 Trello Tarzı İçerik Panosu (Kanban):** Fikir Havuzu, Hazırlanıyor, Onay ve Tamamlandı aşamalarında kart yönetimi ve tek tıkla *"Editöre Aktar"* kabiliyeti.
* **🔐 Güvenli Kullanıcı Oturumu & KVKK:** Web Crypto API (SHA-256) ile istemci taraflı şifreleme ve KVKK Aydınlatma Sistemi.
* **🎨 Amber Studio Teması:** Gözü dinlendiren açık ve koyu mod fırınlanmış kehribar tasarım dili.

---

## 🛠️ Teknoloji Yığını

* **Çekirdek:** React 19, TypeScript
* **Tasarım:** Tailwind CSS v4, Lucide React, clsx, tailwind-merge
* **Derleme & Geliştirme:** Vite 8, Oxlint
* **Kütüphaneler:** html-to-image, Web Crypto API (SHA-256), LocalStorage API
